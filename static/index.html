        04 · How It Works

        From circular to cited answer

        1. 01

          Document

          Official circulars, as PDFs and text files.

        2. 02

          Chunks

          Split into ~500-token passages that overlap slightly.

        3. 03

          Embeddings

          Each passage becomes a vector that captures its meaning.

        4. 04

          Vector search

          Your question is matched to the 3 closest passages.

        5. 05

          Cited answer

          Written only from those passages, citing each source.

        It refuses rather than guesses. If the retrieved passages don't contain the answer, Campusquer says so and logs the question to the Gap Log for the administration.
