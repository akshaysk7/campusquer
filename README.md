# campusquer
## Abstract

A RAG system that answers questions about the campus, cited from official
circulars and information provided by the college itself. Only real,
official data — no guessing, no unsure answers. Unanswered questions are
drafted into a report that can be presented to college management or
discussion forums for conclusive answers.RAG SYSTEM WHICH ANSWERS QUESTIONS REGARDING THE CAMPUS WHICH ARE CITED FROM OFFICIAL CIRCULARS AND INFORMATION PROVIDED BY THE COLLEGE ITSELF. ONLY REAL AND OFFICIAL DATA. NO GUESSING/UNSURE ANSWERS.
